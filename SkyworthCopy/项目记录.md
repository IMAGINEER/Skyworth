### 阶段 4：组件化重构 — Header/Footer 提取

**日期**：2026-03-03
**会话 ID**：同上

> **用户指令**：
> "把 header + nav 部分的HTML提取出来，保存为 components/header-nav.html；
> 把 footer 部分提取出来，保存为 components/footer.html；
> 创建 assets/js/components.js，页面加载时自动插入到占位符位置..."

**实现方案**：
1. 从 `index.html` 提取 header+nav → `components/header-nav.html`
2. 从 `index.html` 提取 footer → `components/footer.html`
3. 创建 `assets/js/components.js`：将组件 HTML 注入到 `id="header-nav-placeholder"` 和 `id="footer-placeholder"`
4. 修改 `index.html`：原位替换为占位符 div，引入 components.js
5. 创建构建脚本 `build-components.mjs`：读取组件源文件，生成 components.js

**构建流程**：
```
components/header-nav.html  ←  人工编辑
components/footer.html      ←  人工编辑
        ↓ node build-components.mjs
assets/js/components.js     ←  自动生成（勿手动编辑）
        ↓ 页面加载时
所有页面                     ←  自动注入 header 和 footer
```

## 五、技术备注

- **技术栈**：HTML5 + CSS3 (CSS Variables) + jQuery
- **构建工具**：Node.js 18+
- **路径规则**：所有路径均为相对路径；`pages/` 下的页面使用 `<base href="../">`
- **导航样式**：pages 中的页面导航默认白色背景（ishover 状态），修改在页面内完成不影响 assets
- **组件更新流程**：编辑 `components/*.html` → 运行 `node build-components.mjs` → 上传 `assets/js/components.js`
- **导航 CSS 修复**：`.hpsr-list { min-height: 400px; }` 防止子产品切换时跳动
