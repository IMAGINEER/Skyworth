# Skyworth PV 设计系统

## 1. 视觉主题与调性

Skyworth Photovoltaic 网站体现了专业、科技感的能源品牌特质。设计融合了清洁的企业美学与现代能源象征——使用让人联想到太阳能和水能的流动渐变、简洁的几何形态，以及传达可靠性和创新精神的留白空间。

整体印象是**专业而不冷淡**——温暖且易于接近。摄影作品展示了完成的安装项目、团队协作和生活方式的画面。

**核心原则：**
- 品牌渐变用于Hero和CTA等核心品牌元素，但不应连续两个区块都使用
- 渐变方向统一为从左到右的流动感
- 下一个区块应使用对比色背景来区分
- 交互元素（按钮）使用渐变，表单输入框不使用渐变文字

## 5. 组件样式

### 主要操作按钮

- 背景：渐变 #006BC0 → #00E2E0
- 文字：白色
- 圆角：80px（胶囊形状）
- 悬停：轻微上移 + 阴影加深
- 过渡：0.4秒

### 次要操作按钮

- 背景：透明
- 边框：2px solid #006BC0
- 文字：#006BC0
- 悬停：背景填充品牌蓝，文字变白

### 文字链接按钮

- 无背景、无边框
- 文字：#006BC0
- 箭头图标悬停时右移

### 输入框

- 高度：60px
- 背景：白色（不是渐变）
- 文字：#1E293B（不是渐变）
- 边框：1px #D8D9E0
- 聚焦：边框变 #006BC0

### 下拉选择框

- 同输入框样式
- 深色侧边栏内可用 #006BC0 背景

### 标准卡片

- 背景：白色
- 圆角：20px
- 阴影：多层叠加阴影系统
- 悬停：上移 + 阴影加深

### 深色卡片

- 背景：渐变 #1E293B → #334155
- 文字：白色
- 用于需要强调的区块

### 标准表格

- 基础样式：`.sm-models-table`
- 圆角：16px
- 溢出处理：`overflow: hidden`
- 表头（thead）背景：渐变 #006BC0 → #00E2E0
- 表头文字：白色，字号 14px，粗体
- 表头圆角：上方 16px
- 表体（tbody）背景：白色
- 表体行hover：#F6FCFF
- 边框：1px solid #D8D9E0
- 单元格内边距：12px 16px

**变体 - 深色表头：**
- 表头（thead）背景：渐变 #1E293B → #334155（用于深色区块内的表格）
- 用于连续深色背景区块中的表格

## 6. 区块设计原则

### 连续区块配色规则

避免连续两个区块都使用品牌渐变背景，会造成视觉疲劳。

推荐配色序列：

| 位置 | 背景 | 文字 |
|------|------|------|
| Hero | 渐变 #006BC0 → #00E2E0 | 白色 |
| 下一区块 | 渐变 #1E293B → #334155 | 白色 |
| 再下一区块 | #F6FCFF 或白色 | 深色文字 |
| CTA | 渐变 #006BC0 → #00E2E0 | 白色 |

### Tab导航控件

**激活状态**
- 背景：渐变 #006BC0 → #00E2E0 或纯色 #006BC0
- 文字：白色
- 与其他Tab形成明确区分

**默认状态**
- 背景：浅色或透明
- 文字：深色或灰色
- 悬停：轻微背景变化

---

## 7. 动画过渡

- 默认过渡：0.4秒
- 卡片悬停：上移4px + 阴影加深
- 按钮悬停：上移2px + 阴影加深
- Tab切换：背景渐变0.4秒

## 8. 设计决策指南

### 何时使用品牌渐变

可以使用：
- Hero大背景（页面开头）
- CTA区块背景
- 主要操作按钮填充
- 卡片内的图标背景

避免使用：
- 连续两个大区块都用渐变
- 输入框文字使用渐变
- 表格表头使用渐变（用 #1E293B 深蓝背景）

### 区块配色示例

Hero（渐变蓝青）→ Problem（渐变深蓝）→ Benefits（浅蓝）→ CTA（渐变蓝青）
