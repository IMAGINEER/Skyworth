## 二、产品定义澄清

### SUN Roof (屋顶款)

- **定义**: 屋顶太阳能系统，包括各种屋顶类型
- **涵盖**:
  - 斜屋顶 (Sloped Roof)
  - 平屋顶 (Flat Roof)
  - 瓦片屋顶 (Tile Roof)
  - 石板屋顶 (Slate Roof)
- **特点**: 根据不同屋顶材料提供专业安装方案

### SUN Loft (阳光房)

- **定义**: 太阳能阳光房/车棚
- **特点**:
  - 2.7m高支柱创造休闲空间
  - 5°坡度设计保证全年采光
  - 遮阳、防雨、隔热
  - TÜV认证 — 抗12级台风

## 五、EPC 服务流程 (家庭场景)

> 参考: `it系统培训.pdf` 第16页 - 项目管理 (EPC模式)

### 家庭光伏 EPC 7步流程

```
┌──────────────────────────────────────────────────────────┐
│  步骤1: 咨询沟通 (Consultation)                          │
│  ─────────────────────────────────────────────────────  │
│  • 了解客户用电需求                                       │
│  • 介绍产品方案                                           │
│  • 初步报价                                              │
├──────────────────────────────────────────────────────────┤
│  步骤2: 现场勘测 (Site Survey)                            │
│  ─────────────────────────────────────────────────────  │
│  • 上门勘测屋顶条件                                       │
│  • 测量屋顶尺寸和朝向                                     │
│  • 检查电路和电表                                        │
│  • 评估安装可行性                                        │
├──────────────────────────────────────────────────────────┤
│  步骤3: 方案设计 (System Design)                          │
│  ─────────────────────────────────────────────────────  │
│  • 根据勘测结果定制方案                                   │
│  • 确定系统功率和配置                                     │
│  • 提供详细报价单                                        │
│  • 3D效果图展示                                         │
├──────────────────────────────────────────────────────────┤
│  步骤4: 申报审批 (Permit Application)                   │
│  ─────────────────────────────────────────────────────  │
│  • 准备申报材料                                          │
│  • 向电网公司提交并网申请                                 │
│  • 获取安装许可                                          │
├──────────────────────────────────────────────────────────┤
│  步骤5: 专业安装 (Professional Installation)             │
│  ─────────────────────────────────────────────────────  │
│  • 材料进场和检验                                        │
│  • 支架和面板安装                                       │
│  • 逆变器和电池安装                                      │
│  • 电气接线连接                                         │
│  • 系统调试                                              │
├──────────────────────────────────────────────────────────┤
│  步骤6: 验收并网 (Commissioning)                         │
│  ─────────────────────────────────────────────────────  │
│  • 电网公司验收                                          │
│  • 并网调试                                              │
│  • 系统试运行                                            │
│  • 客户培训                                              │
│  • 签署验收单                                            │
├──────────────────────────────────────────────────────────┤
│  步骤7: 运维服务 (O&M Service)                           │
│  ─────────────────────────────────────────────────────  │
│  • APP绑定和远程监控设置                                  │
│  • 定期巡检服务                                          │
│  • 质保期内维修                                          │
│  • 售后服务响应                                          │
└──────────────────────────────────────────────────────────┘
```
